JARVIS

Dein lokaler Sprachassistent für Ubuntu.
Wake Word · Whisper · Claude-Agent · Vision · volle Kontrolle.

Code auf GitHub Installation

// Was Jarvis kann

🎙️

Freihändig per Stimme

„Jarvis“ sagen, sprechen, fertig. Wake-Word-Erkennung mit OpenWakeWord oder Porcupine, Spracherkennung mit Whisper — alles lokal.

🧠

Plant & denkt mit

Ein Claude-Agent plant mehrstufige Aufgaben, begründet seine Schritte und nutzt Werkzeuge: Terminal, Browser, Dateien.

👁️

Sieht seine Umgebung

Kameramodul mit YOLO-Objekterkennung — Jarvis beschreibt, was vor der Linse passiert.

📝

Merkt sich Dinge

„Merk dir: Milch kaufen.“ Notizen überleben Neustarts und lassen sich per Stimme abrufen und verwalten.

🧹

Räumt auf

„Räum meine Downloads auf“ — Dateien werden nach Typ sortiert: Bilder, Dokumente, Musik, Videos, Archive. Erst Vorschau, dann Ausführung.

🛡️

Du behältst die Kontrolle

Sicherheitskritische Aktionen laufen erst nach „Ausführen? [Ja/Nein]“. Eine Blocklist stoppt zerstörerische Befehle grundsätzlich.

// Architektur

Wake Word→ Whisper STT→ Claude-Agent→ Tools + Vision→ Piper TTS

// In 2 Minuten startklar

# Repository holen und Umgebung anlegen
git clone https://github.com/Quitboy69/Quitboy69.git && cd Quitboy69/jarvis
python -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt

# API-Key setzen und starten
export ANTHROPIC_API_KEY="sk-ant-..."
python -m jarvis.main            # mit GUI
python -m jarvis.main --console  # ohne GUI

Alle schweren Abhängigkeiten (Whisper, Piper, YOLO, GUI) sind optional — fehlt eine Komponente, schaltet Jarvis automatisch auf einen Fallback um.
